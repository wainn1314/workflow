---

### 各字段填写说明
| 字段 | 填写要点 |
| --- | --- |
| **Role** | 角色定义要具体到细分领域，而非泛泛的"专家" |
| **Background** | 交代清楚业务上下文，让AI理解"在什么环境下做事" |
| **Goals** | 区分核心目标和子目标，形成目标层级结构 |
| **Skills** | 能力模型决定了AI调用哪些知识域，写得越精准效果越好 |
| **Constraints** | 这是LangGPT的核心优势——通过红线约束防止AI跑偏 |
| **Workflow** | 分步执行流程，让AI按序推理而非一次性输出，显著提升复杂任务质量 |
| **Output Format** | 锁定输出结构，确保每次输出格式一致，适合工程化调用 |
| **Initialization** | 初始化指令，让AI确认理解后进入待命状态，等待用户输入 |


---

### 与CRISPE/CO-STAR的核心区别
LangGPT最大的差异在于多了 **Constraints（约束）** 和 **Workflow（工作流）** 两个模块：

+ **Constraints** 解决了"AI不听话"的问题，通过明确红线防止幻觉和跑偏
+ **Workflow** 解决了"复杂任务质量差"的问题，通过分步执行让AI逐步推理

因此，LangGPT更适合**复杂度高、约束多、需要稳定输出**的生产级场景。
