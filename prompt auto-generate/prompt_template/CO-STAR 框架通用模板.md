```markdown
## Context（背景信息）
[描述当前业务场景、行业背景、已有条件]
[说明触发本次任务的原因或前置事件]

## Objective（任务目标）
你需要完成的核心目标是：[一句话描述目标]
具体交付物包括：
- [交付物1]
- [交付物2]

## Style（风格）
请采用[某领域/某人物/某品牌]的写作风格，参考特征：
- [风格特征1，如"数据驱动、逻辑严密"]
- [风格特征2，如"善用类比、降低理解门槛"]

## Tone（语气）
整体语气应保持：[专业权威 / 亲切友好 / 激励鼓舞 / 客观中立]
避免：[不需要的语气特征，如"过于口语化 / 使用网络梗"]

## Audience（受众）
目标读者是：[受众身份描述]
他们的认知水平：[专业 / 半专业 / 零基础]
他们最关心的问题是：[受众核心关注点]

## Response（输出格式）
请按以下格式输出：
- 结构：[标题层级 / 段落数量 / 模块划分]
- 格式：[Markdown / JSON / 纯文本 / 表格]
- 长度：[约XX字 / 控制在XX字以内]
```

---

### 各字段填写说明
| 字段 | 填写要点 |
| --- | --- |
| **Context** | 提供"为什么做"的背景，越具体AI越能理解业务语境 |
| **Objective** | 目标要可衡量，避免"帮我优化一下"这类模糊表述 |
| **Style** | 可引用具体品牌/人物风格，比抽象描述更精准 |
| **Tone** | 同时写"要什么"和"不要什么"，双向约束效果更好 |
| **Audience** | 明确受众认知水平，直接决定AI的用词深度和解释方式 |
| **Response** | 格式约束越具体，输出越稳定，适合批量生产场景 |
