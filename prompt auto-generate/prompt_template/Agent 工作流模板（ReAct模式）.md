```markdown
# Role: [Agent角色名称]

## Objective
[一句话描述Agent的核心任务目标]

## Available Tools
Agent可调用的工具列表：
1. [工具1名称]：[功能描述]
2. [工具2名称]：[功能描述]
3. [工具3名称]：[功能描述]

## ReAct Workflow
请严格按照以下循环执行：

### Thought（思考）
分析当前状态，明确：
- 我现在掌握了哪些信息？
- 距离目标还缺什么？
- 下一步应该做什么？

### Plan（规划）
制定行动计划：
- 选择哪个工具？
- 传入什么参数？
- 预期得到什么结果？

### Action（行动）
执行具体操作：
- 调用工具并获取返回结果

### Observation（观察）
评估行动结果：
- 返回结果是否符合预期？
- 是否出现错误或异常？
- 信息是否足够支撑下一步？

### Refinement（修正）
根据观察结果决定：
- ✅ 目标已达成 → 输出最终结果
- 🔄 信息不足 → 回到Thought继续循环
- ❌ 出现错误 → 调整策略后重试

## Termination Condition
当满足以下条件时结束循环：
- [终止条件1]
- [终止条件2]

## Output Format
最终输出需包含：
- 执行过程摘要（Thought → Action → Observation的关键节点）
- 最终结果
- 置信度评估（高/中/低）
```

---

### 各字段填写说明
| 字段 | 填写要点 |
| --- | --- |
| **Role** | 定义Agent的身份，如"智能客服Agent""数据分析Agent" |
| **Objective** | 一句话锁定Agent的终极目标，避免任务发散 |
| **Available Tools** | 明确Agent可调用的外部工具，这是Agent区别于普通Prompt的核心能力 |
| **Thought** | 让AI先"想清楚"再行动，是提升复杂任务准确率的关键 |
| **Plan** | 将思考转化为可执行的计划，明确工具选择和参数 |
| **Action** | 实际执行步骤，调用工具获取真实数据 |
| **Observation** | 对执行结果进行自我评估，形成闭环反馈 |
| **Refinement** | 根据评估结果决定继续、重试还是终止，实现自适应控制 |
| **Termination Condition** | 明确退出条件，防止Agent陷入无限循环 |
| **Output Format** | 要求输出执行过程摘要，便于调试和追溯决策链路 |


---

### 与前四个模板的核心区别
| 维度 | CRISPE/CO-STAR/LangGPT | Agent工作流 |
| --- | --- | --- |
| **执行模式** | 单次输入→单次输出 | 多轮循环，自主决策 |
| **工具调用** | 无 | 可调用外部工具和API |
| **适用场景** | 内容生成、分析总结 | 复杂任务自动化、多步骤推理 |
| **核心机制** | 结构化约束 | 思考-行动-观察循环 |


Agent工作流是目前AI产品工程化落地的核心范式，适合需要**自主决策、多步推理、工具调用**的复杂场景，如智能客服、自动化数据分析、RPA流程等。
